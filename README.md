# 小紅書直播錄影機 · Windows / Chrome

獨立於 [chrome-tab-recorder](https://github.com/wuwu50/chrome-tab-recorder) 的新專案。指定主播監控、確認直播播放後自動錄影、連續確認下播後背景合併為一部 MP4，然後回到主播個人頁繼續待命。

**0.2.0 是實驗版：錄影／待命生命週期及模擬頁面有測試；尚未完成真實小紅書主播開播到下播的端到端驗證。** 網站改版、驗證或沒有公開直播入口時，會顯示未知／需要注意，不宣稱主播未開播。第一版只支援一位主播、一個保留的分頁。

## 目前直播狀態與通知

開啟指定主播個人頁／直播頁 → 點工具列圖示 →「檢查目前直播狀態並通知」。**不用先選資料夾或啟用錄影**，只讀取目前頁面，不重新整理、不開啟擷取。

介面顯示「直播中」、「目前未開播」、「直播已結束」或「目前無法確認」，同時標示主播 ID、判斷依據及最後檢查時間。只有頁面明確顯示未開播，才顯示未開播；找不到直播入口不等於未開播。檢查結果超過兩分鐘會標示待重新確認。

手動檢查會嘗試送出桌面通知；已啟用待命時，狀態轉為開播／確認下播也會通知，相同狀態不每分鐘重複提醒。通知被 Chrome／Windows 阻擋時，介面仍顯示結果。通知只說明直播狀態，不代表錄影成功，錄影狀態另行顯示。

升級後如 Chrome 要求新增通知權限，請允許；更新前請先解除待命並完成儲存。

## 安裝及使用

Windows 10／11、Chrome 116 以上。下載本專案 Release 的 `RednoteLiveRecorder-0.2.0-Setup.exe` 安裝；若尚未發布 Release，可下載原始碼 ZIP 並解壓縮。

1. 在 Chrome 開啟 `chrome://extensions`，啟用「開發人員模式」，選「載入未封裝項目」，選取本專案的 `extension` 資料夾。釘選「小紅書直播錄影機」。
2. 開啟主播個人頁，點工具列擴充功能圖示 →「開啟獨立控制視窗」→ 選擇實際儲存影片的資料夾並允許寫入。關閉控制視窗。
3. 回到主播個人頁，再點工具列圖示。確認主播 ID，按「啟用目前分頁待命」。預填主播是 `5f0c0b43000000000101fb9c`。
4. 保持 Chrome 和這個分頁開啟。每分鐘檢查一次；若個人頁有可確認的直播入口，會在同一分頁開啟。確認影片正在播放後，才建立錄影檔。如果網站禁止自動播放，需在直播分頁按播放。
5. 連續兩次看見明確的直播結束文字，才停止、背景儲存及返回個人頁。暫停、緩衝、無影片、連線錯誤不會被當成下播。也可以隨時按「解除待命並儲存」。

## 為什麼要先點一次啟用

Chrome 的 tabCapture 要求使用者先對分頁啟用擴充功能。本專案不繞過授權：啟用後保持這個分頁的擷取串流，開播時將其複製給錄影工作，下播後只停止錄影副本，保留待命串流。Chrome 仍會顯示正在擷取分頁；待命不是零資源消耗，但不把等待畫面存成影片。

不要關閉、挪用或跨網站導覽此分頁。Chrome 重啟、擴充功能重載、休眠導致擷取中斷後，要重新啟用。不能在電腦關機或睡眠時監控。離開指定主播頁面會解除待命並嘗試儲存。

自動錄影預設 30 FPS / 8 Mbps，使用既有 MP4 編碼與合併流程；不混入其他分頁、其他程式或麥克風。播放器本身要有聲音；背景／最小化影片的行為仍取決於網站，請先短錄驗證。

## 儲存與救援

啟用待命必須先授權儲存資料夾。檔名為 `小紅書-主播ID-日期時間.mp4`，同名會加編號。保護性分段約 1 GiB／5 分鐘，停止後不重新壓縮地合併為單一 MP4。分段切換可能有短暫缺口。

磁碟滿、資料夾權限失效或合併失敗時保留原始片段；到獨立控制視窗重新儲存或選擇分段救援。不要清除 Chrome 資料或解除安裝，直到待存影片已處理完成。待命中不會自動重載更新。安裝位置、更新通訊協定與儲存空間皆與原錄影機獨立。

## 偵測範圍與限制

- 只讀取已授權的小紅書／rednote 網頁，不登入、不繞驗證、不取得私有 API。
- 個人頁必須呈現帶有「直播中／正在直播」標示的直播連結；不符 host_id 的連結不採用。無法辨識的頁面顯示未知。若網站只提供 JavaScript 按鈕而無直播連結，需要依實際頁面另行適配。
- 分享 token 不寫進原始碼；需要帶 token 才能觀看時，請手動開啟有效連結後啟用。返回個人頁使用同站標準網址，若遭限制請在該分頁處理。
- 開播延遲包含檢查週期、載入和播放時間；不保證錄到第一秒或最後一秒。未知狀態繼續錄影，請留意磁碟空間。
- 只錄製你有權錄製的內容，影片留在本機，不上傳錄影。

## 開發與發布

不需 npm 安裝，使用 Node.js 24 和 Python 3。在專案根目錄執行：

```powershell
node tests/test-live-status.cjs
node tests/test-live-monitor.cjs
node tests/test-standby.cjs
node tests/test-recorder.cjs
node tests/test-save-queue.cjs
node tests/test-background.cjs
node tests/test-audio-routing.cjs
node tests/test-merge.cjs
node tests/test-updates.cjs
node tests/test-installed-update.cjs
python tests/test-publish.py
```

推送 main 會透過 GitHub Actions 測試、編譯獨立 Windows 安裝包、測試安裝／解除安裝、發布 ZIP／EXE 和更新資訊。第一次載入 Chrome 擴充功能仍需手動操作。

沿用原專案錄影核心，來源與第三方授權見 [NOTICE.md](NOTICE.md)。
