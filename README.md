# 小紅書直播錄影機 · Windows / Chrome

獨立於 [chrome-tab-recorder](https://github.com/wuwu50/chrome-tab-recorder) 的新專案。指定主播監控、確認直播播放後自動錄影、連續確認下播後背景合併為一部 MP4，然後回到主播個人頁繼續待命。

**0.5.1 是實驗版：錄影／待命生命週期及模擬頁面有測試；尚未完成真實小紅書主播開播到下播的端到端驗證。** 網站改版、驗證或沒有公開直播入口時，會顯示未知／需要注意，不宣稱主播未開播。第一版只支援一位主播、一個保留的分頁。

## 問題排查紀錄

自動記錄待命操作、每次直播判斷與處理動作、分頁導回、錄影來源核對、錄影／背景存檔狀態與錯誤。流程紀錄最多 500 筆、七天；錄影指標另保留最近 40 筆，存於本機，重開 Chrome 後仍可匯出，不自動上傳。

遇到問題時，到控制視窗下方「問題排查紀錄」，填入簡短描述（選填），按「記下目前異常」，再按「匯出診斷紀錄」。JSON 檔可連同問題發生時間、預期行為和實際情況提供排查。匯出時也會自動記下目前頁面結構數量及播放器就緒狀態；不擷取頁面文字、截圖、影片或 cookies。

網址查詢參數、token 及本機路徑會遮蔽；請勿在問題描述輸入密碼。可按「清除紀錄」刪除診斷資料，不影響錄影及救援片段。診斷儲存失敗不會中斷錄影；沒有紀錄不能當作沒有發生問題。

## 工具列即時狀態

釘選擴充功能後，不必打開控制視窗就能看見角標：

- 灰色「未」：頁面明確顯示未開播／已結束。主頁沒有直播提示仍為「？」。
- 綠色「直」：直播中，但尚未開始錄影。
- 紅色「錄」：實際正在錄影，包括保護性分段切換；其他直播查詢不會蓋掉它。
- 藍色「存」：沒有正在錄影／已確認直播時，顯示影片儲存中。
- 橘色「!」：錄影或存檔需要處理，點擊控制視窗查看。
- 黃色「？」：尚未檢查、無法確認，或單次查詢結果超過兩分鐘。

滑鼠移上圖示可看完整說明、最後直播檢查時間與待命是否啟用。待命期間依原本每分鐘檢查更新；沒有啟用待命時，手動檢查會更新角標，過期後不再沿用舊直播結果。錄影具有最高顯示優先順序；偵測到錄影背景文件消失時不會繼續顯示「錄」。

## 目前直播狀態與通知

開啟指定主播個人頁／直播頁 → 點工具列圖示 →「檢查目前直播狀態並通知」。**不用先選資料夾或啟用錄影**，只讀取目前頁面，不重新整理、不開啟擷取。

介面顯示「直播中」、「目前未開播」、「直播已結束」或「目前無法確認」，同時標示主播 ID、判斷依據及最後檢查時間。主頁即使完整載入且沒有直播提示，也不能證明未開播，一律顯示未知。可貼上本場直播分享連結，導回原擷取分頁核對播放；若尚未待命，開啟直播後再啟用待命。分享連結只供本場使用，不用來推斷下次開播。檢查結果超過兩分鐘會標示待重新確認。

手動檢查會嘗試送出桌面通知；已啟用待命時，狀態轉為開播／確認下播也會通知，相同狀態不每分鐘重複提醒。通知被 Chrome／Windows 阻擋時，介面仍顯示結果。通知只說明直播狀態，不代表錄影成功，錄影狀態另行顯示。

升級後如 Chrome 要求新增通知權限，請允許；更新前請先解除待命並完成儲存。

## 安裝及使用

Windows 10／11、Chrome 116 以上。下載本專案 Release 的 `RednoteLiveRecorder-0.5.1-Setup.exe` 安裝；若尚未發布 Release，可下載原始碼 ZIP 並解壓縮。

1. 在 Chrome 開啟 `chrome://extensions`，啟用「開發人員模式」，選「載入未封裝項目」，選取本專案的 `extension` 資料夾。釘選「小紅書直播錄影機」。
2. 開啟主播個人頁，點工具列圖示，直接開啟唯一的控制視窗。右側選擇儲存資料夾並允許存取，等待「背景寫入檢查已通過」。
3. 在同一控制視窗確認主播 ID，按「啟用指定分頁待命」。預填主播是 `5f0c0b43000000000101fb9c`。不需要在兩個介面間往返。
4. 保持 Chrome、主播分頁及此控制視窗開啟；可以最小化。每分鐘檢查一次；偵測頭貼、頂部提示或首張卡片的「直播中／LIVE」標籤後，自動點擊入口。若網站另開直播分頁，會把直播網址導回已授權的原分頁並關閉該附屬分頁。核對主播、原擷取分頁及影片播放後，才建立錄影檔；介面會顯示來源核對結果。如果網站禁止自動播放，需在直播分頁按播放。
5. 連續兩次看見明確的直播結束文字，才停止、背景儲存及返回個人頁。暫停、緩衝、無影片、連線錯誤不會被當成下播。也可以隨時按「解除待命並儲存」。

## 資料夾與統一控制視窗

工具列圖示、舊版相容入口都會回到同一個控制視窗。直播查詢、待命、自動錄影、手動錄影、資料夾、影片救援與更新都在這裡。再次在其他分頁點圖示會更新目標，不會建立第二套不同步的操作介面。

記住資料夾不等於一直有寫入權限。控制視窗按「選擇／更換資料夾」或「允許存取」後，背景錄影端會在該資料夾建立唯一的短暫檢查檔，實際寫入、關閉並刪除；完成才開放待命。檢查不碰既有影片。權限拒絕、磁碟失敗或清理失敗都不會顯示為已就緒。

**不要照舊版操作關閉控制視窗後回小視窗啟用。** 待命與儲存期間請保留此控制視窗，可以最小化；關閉所有可見的擴充功能視窗可能讓 Chrome 的暫時資料夾權限失效。重新開啟時如顯示權限不足，直接在同一控制視窗按「允許存取」。有待命／錄影／待存影片時，關閉視窗會先提示。

## 為什麼要先點一次啟用

Chrome 的 tabCapture 要求使用者先對分頁啟用擴充功能。本專案不繞過授權：啟用後保持這個分頁的擷取串流，開播時將其複製給錄影工作，下播後只停止錄影副本，保留待命串流。Chrome 仍會顯示正在擷取分頁；待命不是零資源消耗，但不把等待畫面存成影片。

不要關閉、挪用或跨網站導覽此分頁。Chrome 重啟、擴充功能重載、休眠導致擷取中斷後，要重新啟用。不能在電腦關機或睡眠時監控。離開指定主播頁面會解除待命並嘗試儲存。

自動錄影預設 30 FPS / 8 Mbps，使用既有 MP4 編碼與合併流程；不混入其他分頁、其他程式或麥克風。播放器本身要有聲音；背景／最小化影片的行為仍取決於網站，請先短錄驗證。

## 儲存與救援

啟用待命必須先授權儲存資料夾。檔名為 `小紅書-主播ID-日期時間.mp4`，同名會加編號。保護性分段約 1 GiB／5 分鐘，停止後不重新壓縮地合併為單一 MP4。分段切換可能有短暫缺口。

磁碟滿、資料夾權限失效或合併失敗時保留原始片段；到獨立控制視窗重新儲存或選擇分段救援。不要清除 Chrome 資料或解除安裝，直到待存影片已處理完成。待命中不會自動重載更新。安裝位置、更新通訊協定與儲存空間皆與原錄影機獨立。

## 偵測範圍與限制

- 只讀取已授權的小紅書／rednote 網頁，不登入、不繞驗證、不取得私有 API。
- 支援主頁直播連結、頭貼／頂部提示／首張卡片的直播標籤及 JavaScript 點擊入口。單靠外圈顏色或筆記標題不認定直播。網站的實際元素仍可能改版；無法辨識時顯示未知。直播網址 host_id 或直播間主播連結需能核對指定帳號，才開始錄影。
- 分享 token 不寫進原始碼；需要帶 token 才能觀看時，請手動開啟有效連結後啟用。返回個人頁使用同站標準網址，若遭限制請在該分頁處理。
- 開播延遲包含檢查週期、載入和播放時間；不保證錄到第一秒或最後一秒。未知狀態繼續錄影，請留意磁碟空間。
- 只錄製你有權錄製的內容，影片留在本機，不上傳錄影。

node tests/test-audio-routing.cjs
node tests/test-merge.cjs
